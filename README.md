# PhotoSob

Эта программа находит все ваши фотки у вас на компе и собирает их в один архив. Полезно для переноса на другой пк.

---

## Возможности

* Автоматический поиск файлов по всей файловой системе.
* Фильтрация файлов по заданным расширениям (например, поиск изображений).
* Упаковка найденных файлов в единый ZIP-архив с сохранением структуры или уникальных имен.
* Обработка ошибок доступа к системным файлам и директориям.

---

## Требования

Для запуска проекта вам понадобится:
* Python версии 3.6 или выше.
